# Adrish Karak — Portfolio

A Next.js portfolio for a full-stack engineer focused on backend systems and applied AI. Design inspired by chanhdai.com (MIT).

## Run locally

```bash
npm install
npm run dev
```

## Content checklist

- `data/profile.ts` — identity, bio, avatar, contact details
- `data/projects.ts` — featured work, factual highlights and links
- `data/experience.ts` — internships and certificates
- `data/tech-stack.ts` — grouped skills
- `public/adrish-karak.jpeg` — profile image

## Optional environment variables

Create `.env.local` as integrations are added: `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_REFRESH_TOKEN`, `GITHUB_TOKEN`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`.
